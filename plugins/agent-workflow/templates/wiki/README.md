Pages hold what the code cannot say: why a module exists, invariants that must hold, gotchas, decisions.
Structure (module list, dependency map) is not written here; `.dependency-cruiser.cjs` enforces it and `npx depcruise --output-type dot` draws it.

One page per module from `_module.md`. One page per decision from `_decision.md`. `INDEX.md` is generated by `scripts/wiki-lint.sh`; do not edit it.
Link pages with `[[slug]]`. Lint fails on a broken link or missing frontmatter.
